## What CPUBalance actually does, and how it relates to Process Lasso

CPUBalance is a small Windows utility built around Bitsum's ProBalance algorithm, the same one that made Process Lasso known. It watches running processes and temporarily lowers the priority of any process monopolizing the CPU, so the window you're actually working in keeps responding. Priorities return to normal when the load drops.

Beyond that automatic handling, the app logs every action it takes, including process name, time, file path and command line, and the log exports to CSV. There's an exclusion list for processes you never want touched, options to change CPU affinity during a restraint, a switch to disable core parking, and a lower I/O priority setting that applies while a process is restrained. You can also decide whether it's allowed to act on system services, on processes already running at non-normal priority, and on foreground processes or their children.

Both products run on the same core engine, processgovernor.exe, and Bitsum says they work side by side without conflict. The difference is scope. CPUBalance gives you the ProBalance controls from a tray icon; Process Lasso is the full toolkit, with the rest of Bitsum's algorithms and everything else the developer makes. If you want the complete package, buy Process Lasso. If you looked at Process Lasso and only cared about the part that stops a background job from freezing your desktop, CPUBalance is the smaller version of that same part.

It doesn't add CPU capacity, because no software can. What it changes is who gets served first when demand exceeds what the processor can deliver.

## Who should buy CPUBalance, and who should skip it

Buy it if you run long CPU-heavy jobs on the same machine you answer email on, and the machine goes unresponsive while those jobs run. Video encodes, renders and compiles are the usual cases. Buy it if your machine has four cores or fewer, since the fewer cores you have, the more damage one runaway process does. Buy it if you look after an office or shop PC that locks up whenever someone leaves an updater or a browser tab running in the background.

Skip it if your usual fix is closing a few tabs. Task Manager already shows what's eating the CPU, and setting a priority by hand takes ten seconds. Skip it if you're chasing frame rates in games; this manages process priority, and frame rates are a different problem. Skip it if you're on a modern 8-core desktop doing office work, where there's rarely a bottleneck for it to fix.
